# Documentation

The [project README](../README.md) describes what JuMACS is and where the published data live. Detailed documentation lives here:

- [Data sources and curation](data_sources.md) — CEDA records and licences, the source registry, source coordinate conventions, and curation decisions on excluded models.
- [Methodology](methodology.md) — pipeline design, native-level statistics, CF-1.13 conventions and the harmonized altitude-grid products.
- [Published products and the data browser](products.md) — what is published where, and how the static browser is generated.
- [Quality control and evaluation](quality_control.md) — post-download audit, coverage and comparison diagnostics, coverage matrix, and the evaluation-data policy.
- [Development and reproducibility](development.md) — repository layout, the JUWELS/JUDAC workflow, CLI and Slurm entry points.
- [Publication workflow](publication.md) — `make mirror-local` and `make mirror-web`, and what they refuse to do.
