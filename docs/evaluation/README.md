# Evaluation data

Satellite climatologies and observations are independent evaluation sources, never inputs to the primary JuMACS climatology. They must not fill gaps, correct model biases, normalize trends, or select a model automatically.

This tracked directory documents evaluation methods. Store generated machine-readable evaluation results under `products/comparison/evaluation/` and any browser plots under `site/`. The `jumacs evaluate` command compares compatible fields on an overlapping month, latitude and pressure domain. Retain each source's provenance and licence.
